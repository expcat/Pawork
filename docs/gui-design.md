# Pawork Desktop GUI 设计

> 更新：2026-09-10；核对基线：`main / 7a416dd6`。本文统一当前界面合同与 GUI 第二阶段目标。**标注「目标」的内容尚未实现**，实施状态只在 [ROADMAP](ROADMAP.md) 维护；当前行为以源码 / golden 为准，布局与冻结契约以 [架构文档](architecture.md) 为准。产品与包级规格见 [Desktop Spec](spec/desktop.md)、[desktop crate](spec/crates/desktop.md)。

## 1. 产品目标与设计边界

Pawork 是本机 Coding Agent 工作台：用户围绕一个任务阅读、输入、批准工具操作和检查结果；项目与历史任务可随时切换，工作面板在需要时出现。下一阶段改善首页引导、阅读层级、任务 / 内容查找和设置定位，保留已经落地的业务能力。

独立 GPUI 进程经 `pawork-client` 连接 `pawork gui serve`；不嵌入 Core，不直连 Provider、SQLite、Git、PTY、Keychain 或文件索引。继续使用 Rust 构建链、现有深色 token 和 100% / 125% / 150% 字号。关闭窗口、进入设置或收起面板均不取消已进入 Core 的 Run。

本文只规定界面与交互。本阶段不增加 PR / 云任务 / 定时任务目的地，不引入插件市场、浏览器预览、IDE 文件树、浅色 / 跟随系统主题、可调推理档位或新的权限模式。候选能力见 §11，不能因为参考图中有入口就绘制可点击占位。

## 4. 工作台壳与首页

**已实现（GUI2-01，验收状态见路线图）**：侧栏顶部第一行放「任务」和新建，第二行放「筛选 · 项目」与分组切换；任务列表紧随其后。搜索按钮随 GUI2-03 接入真实查找能力。正常连接状态下移至底部 Local / Settings 行；连接失败在主区保留可操作原因与重试，不靠一个红点解释错误。顶部保留 36px traffic lights 非交互安全区。

Header 左侧是任务标题，右侧是当前确有用途的动作。默认 64px 起；不重复显示 Composer 的模型或账号额度。保留 Inspector 重开 / Activity 入口，GUI2-05 完成后再按面板规格整理，不能提前删除唯一可达入口。

首页只显示简短的「开始一个任务」及当前可用下一步，不添加宣传卡或假最近项目。Composer 固定底部；用户不必在首页与对话中寻找两套输入区。

| 真实状态 | 呈现与动作 |
| --- | --- |
| 无 active task、已连接 | 首页说明 + 新建任务；项目定向新建沿用项目菜单；不因渲染首页创建会话 |
| 已有空任务 | 相同欢迎语，输入可直接开始；不再要求创建第二个任务 |
| 无项目任务 | 显示无项目、文件工具不可用及「在项目中新建任务…」；问答仍按现有 gate 可用 |
| 已绑定项目 | 显示 Host 返回的项目，回收无项目限制占用；侧栏筛选不改变该绑定 |
| 无模型 / 全禁用 | 在模型处解释原因，进入供应商设置；不虚构默认模型 |
| 正在连接 / 重连 | 显示进度与现有草稿，禁止发送 / 模型切换 / 审批 |
| 连接失败 / 不兼容 | 可读原因、重试、连接诊断；保留已有 Timeline，不用空态掩盖失败 |

**保留的 TaskRail 行合同**：44px 行、14px 标题、12px 时间；时间与两个 32px 动作共用 64px 尾槽。当前、悬停、键盘聚焦行露出改名 / 归档且不挤动标题；行操作不误开任务。改名 Enter 提交、Esc 取消，空白不提交。分组与项目范围正交，全局新建在 All projects 下创建无项目任务，项目头新建绑定该项目。

## 5. 对话阅读与运行状态

<a id="ui-3-时间线更新2026-09-08进行中"></a>

**目标（GUI2-02）**：短用户消息靠右、按内容收缩，最大占阅读列 80%；长段落自然换行，长代码 / 表格可使用整列并在内容内部滚动。气泡内边距从当前 20px 调整为 12px 纵向 / 16px 横向，保留 12px 圆角。助手正文保持开放排版。保留 32px 消息间距、12px 段距；不以降低字号换取信息密度。

作者、时间和菜单降为辅助层级；菜单在悬停 / 聚焦时可见，键盘和 AX 入口始终有效。用户消息无需重复显示大标题。流式追加只影响当前输出；用户上滚后停止跟随，显式「回到底部」才恢复。工具 / 思考展开、Inspector 开合及窗口缩放须保留当前阅读锚点。

**当前并保留的内容合同**：

- Markdown 支持段落、标题、列表、引用、代码、强调、行内代码和管线表格；不是完整 CommonMark。表格保留对齐和 escaped pipe，代码复制保留原始换行；HTTP(S) 链接可打开 / 复制，未知协议不当可点击地址。
- 思考仅展示可见 thinking，默认收起；不展示 redacted、opaque 或 encrypted reasoning，无来源不显示耗时。工具也默认收起，36px 摘要汇总真实数量与状态，展开显示已有参数 / 结果；缺结果与空结果分开。
- 同 Run 的旧相位由后继终态吸收；成功无真实可审阅文件时仅显示页脚，有文件才提供 Review changes；失败保留原因，取消只留页脚。复制 / Fork 使用已有权限与闭合回合边界，不把任意消息当可分叉边界。
- Context 是当前请求上下文估算 / 模型容量，Run usage 是该轮持久化终态累计用量，订阅 quota 位于账号页。三者不混用，缺失为未知，真实零值有效。

**目标状态密度**：每轮用量仍可在其页脚核查；底部 30px 运行栏只在当前 Run 运行中或有需要处理的状态时出现，空闲已完成状态回收该栏空间。项目限制、连接错误和待审批不得随着普通反馈自动消失。GUI2-02 实施前，现有最近 Run 状态栏保持原样。

审批继续内嵌在 Timeline：工具名、目标、风险 / 摘要与「仅本次允许 / 本轮运行允许 / 拒绝」，无默认允许。查找浮层、面板开合和设置跳转均不能触发审批。

## 6. Composer

<a id="ui-4-输入栏更新2026-09-08"></a>

卡片只承载草稿、当前模型和发送 / 取消。现有 110–220px 卡片预算、16px 内边距和 12px 动作行间距保留；长草稿超过上限后内部滚动。软换行不改原文，光标、选择、点击与 IME 共用布局；每个任务独立保存窗口内草稿。

**目标（GUI2-02）**：模型继续放在 Composer 左下角，显示当前项和必要来源；菜单复用现有搜索，底部增加「管理模型与供应商」导航。运行中 Send 同槽换 Cancel；Enter / Shift+Enter 提示放 tooltip，不常驻占一行。模型与设置入口不能吞掉草稿或绕过 Host 确认。

卡片下方一行组织只读项目 / 无项目限制 / 项目新建入口，Context 靠右；最小窗口或大字号允许自然换行，所有文本与动作均可读。普通反馈只在有内容时出现，字号反馈最后一次调整后 3 秒收起并回收行高；不得清除同时到达的新错误。

| 输入 / 菜单状态 | 必须保持 |
| --- | --- |
| 普通输入 | Enter 发送、Shift+Enter 换行、撤销 / 选择 / 中文输入可用 |
| IME composing | Return 只确认组合，不发送 Run，不触发菜单确认 |
| 空白草稿 | 禁止发送 |
| Run 运行中 | 取消只作用于本轮，模型不切换 |
| 模型搜索 | 打开定位当前项，↑/↓ 高亮并滚入视口，Enter 只选择，Esc 回入口 |
| 目录回退 | 明确目录来源不等于认证成功；完整 provider / model ID 可读 |
| 断线 | 保留草稿，禁发与禁写；原因和诊断可达 |

`@token` 目前由 Host 在 RunStart 展开为独立内容 part，没有 GUI 候选列表。下一阶段不把 `@`、附件、slash 命令或 reasoning 芯片画成已支持操作；详见 §11。

## 7. 查找与定位

**目标（GUI2-03）**：侧栏搜索按钮 / `Cmd+K` 打开同一个浮层。查询框在顶部，结果按任务、页面、导航操作分组，任务显示项目 / 无项目与标题；默认按已有更新时间展示最近任务。匹配当前 Snapshot 中的任务标题 / 项目名及本地页面标题，不建立数据库索引。

浮层宽度目标为可用宽度内最多 640px，高度最多视口 60%；头部固定，结果列表滚动，行高随内容 / 字号增长。输入不切任务，↑/↓ 选择，Enter 执行一个既有导航动作，Esc 关闭并回到原控件。任务打开后保留各自草稿；结果被项目筛选遮挡时解除筛选并说明，不重绑项目。无结果显示清除查询，不能默认执行新建或发起 Run。

**目标（GUI2-04）**：Header 的查找入口 / `Cmd+F` 只查当前已加载用户 / 助手正文，显示命中位置、总数及前后按钮；首次只定位整条消息，正文内精确字符高亮不作为首片要求。工具输出、思考和所有其他会话不在首片搜索范围，界面明确范围，分页未完整时标「已加载内容」。

长对话增加按用户消息摘要排列的回合目录。内容超过一屏且含多个回合才出现入口，打开后选一回合定位；先实现列表，不做永久 minimap 或悬停预览。定位键采用 session + 稳定 event/message 身份，渲染前重新映射虚拟列表行号，不能长期缓存易变化的像素偏移 / 数字索引。

查找和目录共享同一条定位路径。跳转脱离跟随，流式新内容不抢走视口；关闭查找不自动回底，切任务清除命中和目录选择。没有找到未加载内容不等于整个历史不存在该内容。

## 8. 工作面板

**目标（GUI2-05）**：面板头显示当前名称、下拉选择器与关闭按钮；候选只包含实际已接通的 Changes / Terminal / Resources。名称选择器取代三项固定页签，保留键盘、焦点和实测 AX。Changes 内的 Files / Summary 在实际需要时保留，不再添加并列工具栏。

默认仍收起，明确点击 Header、Activity 或 Review 才打开；工具完成不自动抢占阅读区。宽窗同一 440px 面板并排；空间不足时显式打开则占用中央 Workspace，左侧任务栏保留，顶部提供「返回对话」。此时隐藏 Timeline / Composer 的渲染和离屏 AX，保留实体、草稿、阅读锚点与连接状态。

窗口变宽时将同一面板放回侧栏；变窄时仅已打开面板进入中央模式，未打开时保持对话。返回 / 关闭恢复原任务视图。切任务继续现有 workspace / session 隔离逻辑，不保留上一任务的 Changes 或终端草稿到新任务。收到审批时提示「返回对话处理审批」，不默认批准、不把审批埋进已隐藏视图。

| 面板 | 当前并保持的能力 | 空态 / 失败的下一步 |
| --- | --- | --- |
| Changes | Host 权威 Git 文件、diff、增删数量；只读 | 无项目指向项目新任务，无变更明确空态；保留 latest-session 与 active-session 不一致提示 |
| Terminal | 创建、输入、尺寸、Stop / Close 与退出状态；ANSI/VT 过滤后的纯文本 | 就地解释只读 / 断线 / 启动失败，按实际 gate 提供设置或诊断；不自动放宽权限 |
| Resources | MCP server / tool 状态与刷新 | 无配置指向 Tools & MCP 的真实配置说明；不冒充文件树或已加载规则页 |

面板打开不创建 PTY，关闭面板不关闭 PTY，窗口退出不取消 Run。运行中 I/O 失败仍保留终端可操作状态；旧权限 stale 时不据此作确定性拒绝。宽窗沿用 180ms 开合并从当前宽度反向续接，跨窄窗布局切换不做穿越不可用区域的动画。

## 9. Settings

<a id="ui-5-设置更新2026-09-08"></a>

Settings 是独立目的地，保留八页顺序：Models & providers、Network、Approvals、Tools & MCP、Terminal、Appearance、Advanced、About。进入时工作台不渲染，返回恢复任务、阅读位置、草稿、Inspector 和 Run；离开设置清除 secure 编辑缓冲，不能把凭证文字带入搜索。

**目标（GUI2-06）**：返回按钮下增加「查找设置」，只查标题、公开说明与中英文别名；与 `Cmd+K` 共用页面 / 设置条目。选择命中先切页，再将实际行滚入视口并短暂标识，焦点落在对应可操作控件或只读行。它是导航，不自动保存或修改值。当前能力不可用的页不出现可执行结果；Advanced 与本地 Appearance 按既有离线行为保留。

设置内容继续全宽、左右 32px。每行清楚区分名称、说明、当前值和动作，描述与输入不过度并列；窄窗 / 大字号将控件移到下一行。导航选中只改变背景 / 字重，文字坐标不移动。除了供应商 / 账号这类实际分组，不给每个普通设置再包一层卡片。

<a id="ui-6a-供应商更新2026-09-08"></a>
<a id="ui-6b-账号交互更新2026-09-08"></a>
<a id="ui-6b-g2-额度交互更新2026-09-09"></a>
<a id="ux-06-供应商与账号信息层级2026-09-09"></a>

**Models & providers 保留合同**：

- 已连接供应商优先，同组稳定排序；概览显示名称、连接、目录来源与启用数。目标为详情按需展开，账号 / 额度、账号操作、添加入口在前，代理与模型管理在后；不重复铺四套状态。
- 认证成功与目录成功分开。目录搜索按名称 / ID；打开定位当前项，固定搜索 / 状态 / 全目录计数 / 批量动作，列表独立滚动。全开 / 全关始终作用完整供应商目录，筛选不缩小范围。
- 四默认角色在供应商列表后；候选为已连接且已启用模型，失效默认可 Clear。识图 / 搜索仍标「尚未生效」，不因视觉重排暗示已接路由。
- 账号按 ID 绑定操作，Use 仅影响该供应商后续请求；验证失败保留旧账号与选择。Remove 行内确认，取消不删除；仍有其他记录时删除当前选中账号须先切换。env 不列为可删除账号。
- Go 账号按 Host 返回展示 5 小时 / 周 / 月额度；多个 key 的共享额度不相加。缺值未知，来源、更新时间、已用 / 剩余各自对应。超过 30 秒、失败、到重置时刻或异常来源时间标过期；倒计时用天 / 小时 / 分钟，分钟向上取整。
- 「额度耗尽时切换」保持 ADR-060 的版本 / 账号 gate、默认关闭与手动选择后关闭语义；不因查找或面板交互触发。刷新保留旧读数并标加载，离页 / 断线 / 删除使旧请求失效。
- 普通 UI / AX summary 不泄露 credential 片段、endpoint 或 raw 错误。secure 输入只在认证编辑中出现，完整值不进 AX / 日志 / 搜索，离开设置清缓冲。OAuth 只展示 Host 返回的 HTTP(S) 授权链接和存在的 device code；到期收起动作。

其余设置仍使用现有范围：Network 只写 Global proxy；Approvals 保持五档与项目信任；Tools & MCP 提供真实 Test / Remove，空态解释平台配置路径、配置节与重启刷新；Terminal 默认只影响之后新建；Appearance 只提供现有字号 / 中英文与深色主题说明；Advanced 保留离线连接诊断，About 以当前认证握手的 `host_data_dir` 为可用条件。

Host-backed 结果断线后标 stale，鼠标 / 键盘 / AX 写入同 gate；最终值以 Host 回执为准。账号、额度、目录权威细节见 [Settings Spec](spec/settings.md)，不在本次规划中变更。

## 10. 状态、键盘与实现约束

<a id="ux-09-文案字号反馈与终端信息2026-09-10"></a>

界面中文统一使用「任务、项目、Pawork 服务」；Run 指一次运行，Session 为任务会话内部术语。只翻译 chrome，不改用户标题、路径、模型 ID、工具输出或原始错误。`New session` 占位标题只作显示本地化，不写回。render 与 AX 使用相同文案、状态与实际可见框，离屏控件不发布动作。

| 事件 / 操作 | 必须保持的结果 |
| --- | --- |
| 连接失败 / 重试 | 原因与尝试状态可见；草稿保留；模型、发送与审批受同一连接 gate 约束 |
| 查询 / 设置失败 | 错误留在发生处，保留当前输入与旧确认值，不弹成无来源的全局成功提示 |
| 字号反馈到期 | 只清自己的 3 秒反馈，新错误 / 项目限制 / 归档撤销不受影响 |
| 菜单操作 | ↑/↓、Enter / Space、Esc 与鼠标同源；焦点离开菜单回入口，不触发底层 Composer |
| `Cmd+K` / `Cmd+F` | 新增动作仅导航 / 查找，不覆盖编辑、审批或取消的既有键位 |
| 既有快捷键 | `Cmd+N` 新任务、`Cmd+I` 面板、`Cmd+.` 取消、字号与任务切换、审批键保留原 gate |
| 系统输入与 AX | 真实 composing 和像素命中需实窗验证；AX 树存在不等于像素正确或完整无障碍合规 |

UI / projection / controller / platform 四层不变。projection 保持纯状态，controller 只调用 client，所有异步 client 调用在 tokio runtime 上；GPUI 前台不直接 await 网络路径。查找目录与布局只保存本地显示状态，不增加业务持久化。

Snapshot 不含历史正文。首连按 Snapshot / subscribe / SessionGet 分页构建 Timeline，缓冲 live 并去重；连续 replay 续接，SnapshotRequired 用新基线替换 stale 并重新分页。查找不能绕过该恢复过程，也不能把页内位置当永久消息身份。相关数据出口见 [AppQuery](../crates/protocol/src/app/query.rs)；`@token` 接线见 [run_start](../crates/app/src/gui_host/handlers/run_start.rs)。
