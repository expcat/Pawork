## 1. 目标、依据与完成条件

用户要求「对所有 UI 元素进行分析后先进行设计再开启新的目标对话逐步开启新对话执行优化」。本轮先完成设计；后续由一个目标对话按 UI-01 → UI-08 串行开启实施对话。目标是改善文字阅读、视觉层级、操作反馈和不同界面之间的一致性。

设计以当前 `main`（起点 `682605ba`）、源码与本轮真窗口截图为依据。截图使用现有本机构建，未重新编译；因此截图证明该产物的外观，涉及行为的结论仍需核对当前源码。此前已完成的 GUI2 / GUI3 不重新登记为待做。

主参考仍为 [PI-Desktop 官方截图页](https://pi-docs.aiuo.net/guide/screenshots)（2026-10-22 重读）。本轮实际查看了 [深色首页](https://pi-docs.aiuo.net/assets/home-dark.DdHw0WDg.webp) 和 [深色设置](https://pi-docs.aiuo.net/assets/dark-settings.D2VaMlEv.webp)。参考的价值在于紧凑的壳、清楚的文字层级、对齐的行与克制的强调色；其截图来自 capture fixture，不是 Pawork 功能证据。下文尺寸是 Pawork 的设计决定，不声称来自参考像素测量。

保持纯 Rust / GPUI、现有深色主题、Host / client 边界与原有 gate。本任务不扩充 Provider、协议、权限模式、IDE 能力或持久设置项，不引入字体包或生产依赖。视觉稿中的示例内容仅用于检查排版。

完成标准：八批所列缺口落地；受影响的现有回归通过；关键界面在真实窗口中检查默认 / 最小窗口及三档字号；设计、实现、自动验证、人工验收分别记录。自动截图检查不记为用户人工验收。

## 4. 统一视觉设计

### 4.1 字体与排版

继续使用 GPUI 系统 UI 字体与中文 fallback；代码使用 `font::MONO`（Menlo）。英文、中文、数字在同一用途上共用字号和基线，不用整页加粗制造层级。消除正文代码区残留的泛用 `monospace`，终端既有字体偏好仍按原合同。

| 用途 | 100% 字号 / 行高 | 字重 | 应用 |
| --- | --- | --- | --- |
| 首页标题 | 28 / 36px | 600 | 仅欢迎标题 |
| 设置页标题 | 24 / 32px | 600 | 九页共同页头 |
| 独立窗口标题 | 20 / 28px | 600 | Plan / Goal / Recording / Video / Drawing / Usage |
| 任务页头 | 18 / 26px | 500 | 当前任务名 |
| 分区 / 面板标题 | 16 / 24px | 500 | Settings section、Inspector、工具卡标题 |
| 对话 / Composer 正文 | 16 / 26px | 400 | 中文长文、输入、Markdown 段落；强调片段按 Markdown |
| 控件 / 列表 / 字段值 | 14 / 20px | 400，当前项 500 | 按钮、菜单、任务行、表单、可操作行 |
| 说明 / 状态正文 | 14 / 22px | 400 | 空态、错误摘要、表单说明、权限目标摘要 |
| 辅助信息 | 12 / 18px | 400 | 时间、数量、来源、快捷键；不承载唯一的操作原因 |
| 代码 / Diff / 日志 | 14 / 22px | 400 | Menlo；等宽数值与双列行号对齐 |

125% / 150% 延用 rem 放大，文字测高与呈现必须使用相同字号和行高。容器用最小高度与内容撑高，不能把文字裁进固定 px 高度。任务行继续使用现有 36px，只有真窗出现裁切时才调整其必要尺寸，并同步覆盖槽、测量和 AX。

在现有 `theme::font` 与组件中表达必要值，不新建 Typography 框架，不一次替换所有同值常量。各页面在所属批次按用途迁移；已经满足的字号不反复改动。

### 4.2 色彩、层次与控件

沿用 canvas `#141416`、panel `#0e0e10`、menu `#1c1c1f`、raised `#222226`、hover `#2c2c31`。正文 / 次要 / 辅助继续用 `#f2f2f3` / `#aaaab2` / `#9b9ba4`。优化靠用途、间距和对齐，不新增主题或装饰性渐变。

普通结构用留白与单条细分隔线。输入框、被选行和菜单各自有可辨认的表面；卡片不层层套边框。圆角保持控件 6px、菜单 / 列表 8px、内容卡 12px、Composer 16px。

蓝色 `#2f6fed` 用于当前可提交的主动作、链接与焦点。筛选、语言、字号、Tab 的选中态用中性 raised / hover + 字重 + check / 下划线，不能仅以颜色表达选中。审批的允许 / 拒绝语义色、Diff 加减色保留，不借视觉优化改变安全语义。

文字按钮最小高 36px，普通图标动作 32px、页头 / Composer 主动作 36px，图标 16px、主发送 18px。大字号通过内容撑高；快捷按钮可以紧凑，但不能以 12px 小字替代常用操作。焦点 ring 2px，不挤动内容。禁用态保持原因可读；tooltip 不成为唯一解释。

图标使用已有 SVG 资产与 `Icon`；为 Plan（清单）、Goal（目标）、Recording（录制）、Drawing（画笔）、Video（视频）、Computer（显示器）、Browser（浏览器）选择准确符号。若资产缺失，仅补必要 SVG；不引入图标依赖或自制另一套组件。

### 4.3 全局几何与动效

保持 1440×1024 初始窗口、1080×720 最小窗口，以及当前 Rail / Inspector 宽度和 Side / Center 切换条件。阅读列拟从最大 880px 收至 800px，左右至少 28px；实际可用宽度不足时自然铺满。此值须在 UI-02 与真实中英文长文比较，若只增加折行而未改善阅读，则保留 880px，并在状态记录写明理由。

间距沿用 4 / 8 / 12 / 16 / 24 / 32px。Settings 全宽壳保留；常规表单行的标签 / 说明区最多 480px、编辑区 240–320px，合计布局预算约 840px，窄处上下排列。Provider 列表、模型表与日志仍可使用全宽，不给整个设置页重新套统一的窄列。

保留 120ms Switch 与 180ms Inspector；hover、pressed、focus 即时。异步动作立即进入真实在途态，成功回执后再确认。静态骨架用于首次加载；刷新保留内容与 stale 标记，不能闪回空白。无需新增循环动画。
