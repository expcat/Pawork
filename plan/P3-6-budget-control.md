# P3-6：预算控制

> Phase 3 · Agent Loop · 状态：🟡未开始 · 依赖：P3-1

**最终目的**：实现多维预算控制（迭代 / 工具 / 时间 / token / 费用 / 输出 / artifact / 并发上限），达预算产生事件而非静默停止，让 Run 开销可控可观察。

**涉及范围**：`agent-engine`

## 细分步骤

1. **定义预算维度** —— 迭代/工具/时间/token/费用/输出/artifact/并发。目的：全覆盖。
2. **达预算产生事件** —— 目的：不静默停，可被观察与处理。
3. **软/硬上限** —— 目的：可警告可强制。
4. **预算耗尽测试** —— 目的：边界正确。

## 主要产出物

- 预算控制器

## 验收标准

- [ ] 达预算产生事件、不静默停
