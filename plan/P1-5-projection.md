# P1-5：Projection

> Phase 1 · 基础设施 · 状态：🟡未开始 · 依赖：P1-4

**最终目的**：实现可重建投影（messages/runs/tool_calls 等），让查询走投影而非全量扫事件，且投影可删后从事件重建。

**涉及范围**：`session-store`

## 细分步骤

1. **定义投影表** —— messages/runs/tool_calls。目的：查询友好。
2. **事件 → 投影 更新器** —— 目的：投影随事件演进。
3. **投影重建（删后从事件重放）** —— 目的：投影可重生。
4. **一致性测试（投影 == 重放结果）** —— 目的：投影与事件一致。

## 主要产出物

- 投影表 + 更新器 + 重建

## 验收标准

- [ ] 投影可删后从事件重建
- [ ] 投影与事件重放结果一致
